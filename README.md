* **DevSecOps First:** Built with an enterprise-grade CI/CD pipeline featuring SAST audit (`govulncheck`, `gosec`), container vulnerability scanning (`Trivy`, **0 CVEs**), and strict unit test coverage thresholds.
* **Automated Supply Chain:** Fully automated multi-platform release flow via GoReleaser v2, Telegram pipeline alerts, and published as a native **GitHub Action**.
